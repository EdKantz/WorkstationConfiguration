# CudaText setup

## Custom plugins

- Plugins need to be added to a specific location in the settings directory. The settings directory differs by operating system.
  - MacOS location: `/Users/ek/Library/Application Support/CudaText`
- Plugins go in `py`
- Restart CudaText and access plugins from the command pallet `Cmd+shift+p` by searching the name. Use F9 when highlighted to set a keyboard shortcut
